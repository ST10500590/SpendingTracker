# SpendingTracker
An Android app to monitor your daily spending

Purpose of Application

The Spending Tracker application is a native Android app designed to help users Monitor how they spend their money on daily items. Users are presented with options to view their weekly spending details or Calculate the remaining budget and must decide whether each statement is a Hack (True) or Myth (False). The application provides immediate feedback and explanations to support learning

Application Logic

The Application basically summarizes everything into one activity , parallel arrays that store the weeks data
The for loops loop the arrays for both displaying and calculation
The functions keep the user interface consistent
The Handler based delayed navigation transitions the splash screen to the main screen
All the buttons are wired to a working function and the calculate screen performs the required per day and weekly budget calculations in a single prompt
